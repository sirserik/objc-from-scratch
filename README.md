# Objective-C с нуля

Учебник по **Objective-C** для русскоязычного читателя — с абсолютного
нуля до динамического runtime и Foundation. В той же серии, что и
«Алгоритмы и игры на Си»: строим с нуля, разбираем каждую строку, весь
код компилируется и запускается, термины сверены с документацией Apple.

## Что внутри

- **Часть 0–1. База Си.** Ровно столько, сколько нужно для объектной
  части: переменные, типы, указатели, память, массивы, строки. По ходу
  всей книги — врезки «Отличие от Си».
- **Часть 2. Объектная модель.** Объекты и сообщения, классы, свойства,
  наследование, протоколы, категории, блоки.
- **Часть 3. Память и runtime.** ARC и ручное управление памятью; большая
  глава про runtime: `isa`, метаклассы, дерево классов, `objc_msgSend`,
  message forwarding, интроспекция.
- **Часть 4. Foundation.** Строки, числа, коллекции, даты/данные/URL,
  файлы и сериализация, KVC/KVO, многопоточность и run loop.
- **Часть 5. Современный Objective-C** и взаимодействие со Swift.
- **Приложения:** A — иерархия классов Foundation, B — шпаргалка
  синтаксиса, C–F — задачи с собеседований (гид, Junior, Middle,
  Senior), G — Objective-C глазами C++-разработчика.

## Сборка

Нужны: `clang` (Xcode Command Line Tools), `pandoc`, `xelatex` (MacTeX),
шрифты PT Serif / Helvetica Neue / Menlo (есть в macOS).

```sh
make check   # скомпилировать все примеры из code/
make pdf     # собрать PDF учебника
make tasks   # собрать отдельный PDF с задачами собеседований
make all     # всё сразу
```

PDF: `Objective-C-s-nulya.pdf` и `Zadachi-s-sobesedovaniy-po-Objective-C.pdf`.

## Структура

```
docs/tutorial/*.md   — главы
code/*.c             — примеры на чистом Си (вводные главы)
code/*.m             — примеры на Objective-C (ARC + Foundation)
code/*.mrr.m         — примеры без ARC (ручное управление памятью)
code/*.cpp, *.mm     — C++ и Objective-C++ (приложение G)
build/               — скрипты сборки, метаданные, style guide
```

Перед написанием/правкой глав — читать `build/STYLE_GUIDE.md`.
