## Переменные и типы

**Переменная** — это коробка с именем, в которой лежит значение. Чтобы
завести коробку, в Си надо сразу сказать, *что* в ней будет лежать —
указать **тип**. Тип определяет, какие значения влезут и сколько места
займут.

Четыре типа, которых пока хватит на всё:

- `int` — целое число: `-3`, `0`, `42`. Без дробной части.
- `double` — число с дробной частью: `3.14`, `199.90`. («double» —
  потому что под него отводится двойная точность.)
- `char` — один символ: `'A'`, `'?'`. В одинарных кавычках.
- `_Bool` — логическое: правда или ложь. Если в начале файла написать
  `#include <stdbool.h>`, появятся понятные имена `bool`, `true`, `false`.

Заведём по одной коробке каждого типа. Создай файл `02-vars.c`:

```c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int age = 19;
    double price = 199.90;
    char grade = 'A';
    bool isStudent = true;

    printf("Возраст: %d\n", age);
    printf("Цена: %f\n", price);
    printf("Цена (2 знака): %.2f\n", price);
    printf("Оценка: %c\n", grade);
    printf("Студент: %d\n", isStudent);

    age = age + 1;
    printf("Через год: %d\n", age);

    return 0;
}
```

Разберём построчно.

`#include <stdio.h>` — подключаем заголовок «standard input/output».
Оттуда берётся `printf` (печать на экран). Без него компилятор не знал
бы, что это за функция. `#include <stdbool.h>` даёт слова `bool`, `true`,
`false`.

> **Отличие от Си.** В Си подключают заголовки через `#include`, как
> здесь. В Objective-C ты уже видел `#import <Foundation/Foundation.h>` —
> он делает то же самое, но не вставит один и тот же заголовок дважды.
> Сейчас, в чистом Си, остаёмся на `#include`.

`int main(void)` — главная функция, точка входа. Ровно та же, что в
главе 1: тут отличий между Си и Objective-C нет вообще.

`int age = 19;` — заводим коробку `age` типа `int` и кладём в неё `19`.
Знак `=` здесь — **присваивание**, «положи правое в левое». Это не
равенство из математики! Запомни сразу, потому что чуть позже встретится
`==` — а вот это уже сравнение. Перепутать их — ошибка номер один у
новичков.

`char grade = 'A';` — символ пишем в **одинарных** кавычках. Двойные
кавычки `"A"` в Си означают совсем другое — строку (про них в главе 4).

Точка с запятой `;` в конце каждой инструкции обязательна.

### Печать через printf и спецификаторы

`printf` печатает текст. Внутри строки прячутся **спецификаторы** —
значки со знаком `%`, на место которых подставляются значения:

- `%d` — целое (`int`),
- `%f` — дробное (`double`),
- `%c` — один символ (`char`),
- `\n` — перевод строки (без него всё слиплось бы в одну строчку).

`printf("Возраст: %d\n", age);` — берёт `age`, подставляет вместо `%d`,
переводит строку. `%.2f` — то же `%f`, но округлить до 2 знаков после
точки.

`age = age + 1;` — читаем правую часть (`age + 1` = `19 + 1` = `20`) и
кладём результат обратно в `age`. Теперь там `20`.

Компилируем и запускаем. Команда — без `-framework Foundation`, он тут
не нужен, это чистый Си:

```text
clang -std=c11 -Wall -Wextra -O2 code/02-vars.c -o vars
./vars
```

Вывод:

```text
Возраст: 19
Цена: 199.900000
Цена (2 знака): 199.90
Оценка: A
Студент: 1
Через год: 20
```

Обрати внимание на две вещи. `%f` без уточнения печатает кучу нулей —
`199.900000`; для денег почти всегда хочется `%.2f`. А `bool` печатается
как `1` (правда) или `0` (ложь) — отдельного «true/false» у `printf` нет.

> **Отличие от Си.** `printf` печатает только примитивы — числа, символы,
> си-строки. Объект ему не скормишь. В Objective-C для печати есть
> `NSLog` со спецификатором `%@` — он умеет печатать любой объект,
> спрашивая у него самого, как тот выглядит (ты видел `NSLog(@"%@", …)`
> в главе 1). Грубо: `%d`/`%f`/`%c` — мир Си, `%@` — мир объектов.

## Арифметика и ловушка целочисленного деления

Складывать, вычитать и умножать Си умеет ожидаемо: `+`, `-`, `*`. А вот
с делением есть подвох, на котором спотыкаются все. Разберём его методом
«сначала наивно, потом чиним».

Задача: 7 яблок разделить на 2 человек. Руками понятно — по 3,5. Напишем
в лоб. Файл `02-divide.c`, наивная первая версия:

```c
#include <stdio.h>

int main(void) {
    int apples = 7;
    int people = 2;

    int bad = apples / people;
    printf("Целочисленно: 7 / 2 = %d\n", bad);

    return 0;
}
```

Запускаем:

```text
Целочисленно: 7 / 2 = 3
```

Не 3,5, а **3**. Куда делась половина? Вот в чём дело: когда `/` делит
**целое на целое**, результат тоже целое — дробная часть просто
отбрасывается (не округляется, а отрезается). `7 / 2` даёт `3` и теряет
остаток. Это и есть **целочисленное деление**.

Остаток, кстати, можно достать отдельным оператором `%` (он так и
зовётся — «остаток от деления», или «модуло»):

```c
    int rest = apples % people;
    printf("Остаток: 7 %% 2 = %d\n", rest);
```

(Внутри строки формата сам знак процента пишется как `%%` — иначе
`printf` примет его за начало спецификатора.)

Теперь чиним главную проблему. Чтобы деление было дробным, хотя бы одно
из чисел должно быть `double`. Превратим `apples` в дробное прямо в
выражении — это называется **приведение типа**, пишется типом в скобках
перед значением: `(double)apples`. Полный `02-divide.c`:

```c
#include <stdio.h>

int main(void) {
    int apples = 7;
    int people = 2;

    int bad = apples / people;
    printf("Целочисленно: 7 / 2 = %d\n", bad);

    int rest = apples % people;
    printf("Остаток: 7 %% 2 = %d\n", rest);

    double good = (double)apples / people;
    printf("Дробно: 7 / 2 = %f\n", good);
    printf("Дробно (2 знака): %.2f\n", good);

    return 0;
}
```

`(double)apples` говорит: «возьми `apples` и в этом выражении считай его
дробным». Дальше `double / int` уже даёт `double`, и половина не теряется.
Запускаем:

```text
Целочисленно: 7 / 2 = 3
Остаток: 7 % 2 = 1
Дробно: 7 / 2 = 3.500000
Дробно (2 знака): 3.50
```

Запомни правило: **`int / int` — всегда целое**. Хочешь дробь — сделай
дробным хотя бы один операнд. Эта ловушка будет преследовать тебя и в
Objective-C, и в любом си-подобном языке.

## Ввод с клавиатуры через scanf

Пока все числа были вшиты в код. Дадим программе прочитать число от
пользователя. За ввод отвечает `scanf` — зеркало `printf`: тот печатает,
этот читает. Файл `02-input.c`:

```c
#include <stdio.h>

int main(void) {
    int age = 0;

    printf("Сколько тебе лет? ");

    int got = scanf("%d", &age);
    if (got != 1) {
        printf("Это не число.\n");
        return 1;
    }

    printf("Через 10 лет тебе будет %d\n", age + 10);
    return 0;
}
```

Главная новая деталь — `scanf("%d", &age)`. Спецификатор `%d` тот же, что
у `printf`: «жду целое». А вот знак `&` перед `age` обязателен и важен.

`&age` — это **адрес** переменной `age`, то есть «где в памяти лежит её
коробка». `scanf` нужно не значение `age` (оно ему ни к чему — он сам его
впишет), а место, *куда* положить прочитанное. `&` и означает «вот сюда».
Забудешь `&` — программа, скорее всего, упадёт. Подробно адреса и знак
`&` разберём в главе 3 про указатели; пока запомни правило: **в `scanf`
перед переменной ставь `&`**.

`scanf` возвращает число успешно прочитанных значений. Мы просили одно —
значит, при удаче вернётся `1`. Поэтому проверяем: `if (got != 1)` —
«если прочиталось не одно значение» (например, пользователь ввёл буквы) —
сообщаем об ошибке и выходим с кодом `1` («что-то пошло не так»). Это
хорошая привычка: всегда проверять, что ввод реально прочитался.

Запускаем и вводим `25`:

```text
Сколько тебе лет? 25
Через 10 лет тебе будет 35
```

А если ввести буквы вместо числа:

```text
Сколько тебе лет? Это не число.
```

Проверка сработала — программа не стала считать мусор.

## Ветвления: if и else

Программа становится интересной, когда умеет **выбирать** путь. За это
отвечает `if` («если»). Поставим оценку по баллу. Файл `02-branch.c`:

```c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int score = 75;

    if (score >= 90) {
        printf("Отлично\n");
    } else if (score >= 60) {
        printf("Зачёт\n");
    } else {
        printf("Пересдача\n");
    }
```

Читается почти как по-русски. `if (score >= 90)` — «если `score` больше
или равно 90, выполни блок в фигурных скобках». Если условие ложно,
проверяется следующий `else if`, и так далее. `else` без условия —
«во всех остальных случаях».

Операторы **сравнения** — те самые, что дают «правду» или «ложь»:

- `>` больше, `<` меньше,
- `>=` больше или равно, `<=` меньше или равно,
- `==` равно, `!=` не равно.

Вот оно, обещанное `==`. Сравнение — это **два** знака равенства. Один
знак `=` — присваивание (положить значение). Их легко перепутать, и
компилятор с `-Wall` обычно предупредит, если в `if` затесалось
одиночное `=`.

Условия можно соединять **логическими** операторами:

- `&&` — «И»: истинно, когда истинны оба условия,
- `||` — «ИЛИ»: истинно, когда истинно хотя бы одно,
- `!` — «НЕ»: переворачивает значение наоборот.

Допишем в тот же файл:

```c
    int age = 20;
    bool hasTicket = true;
    if (age >= 18 && hasTicket) {
        printf("Проходи\n");
    }

    if (!hasTicket || age < 18) {
        printf("Стоп\n");
    } else {
        printf("Всё в порядке\n");
    }

    return 0;
}
```

`age >= 18 && hasTicket` — «совершеннолетний И с билетом». Оба верны (20 и
`true`), значит печатается «Проходи». `!hasTicket || age < 18` — «нет
билета ИЛИ младше 18»; оба ложны, поэтому срабатывает `else` со «Всё в
порядке». Запускаем весь `02-branch.c`:

```text
Зачёт
Проходи
Всё в порядке
```

`score` равен 75 — не дотянул до 90, но прошёл порог 60, отсюда «Зачёт».

> **Отличие от Си.** Сравнение `==` отлично работает для чисел: `5 == 5`
> истинно. Но для **объектов** в Objective-C `==` сравнивает не
> содержимое, а адреса — «это буквально один и тот же объект в памяти?».
> Чтобы сравнить две строки *по тексту*, нужен метод
> `[a isEqualToString:b]`, а не `a == b`. Это классическая ловушка, и мы
> вернёмся к ней в главе 15 про `NSString`. Пока — для чисел `==` честно
> сравнивает значения.

## Циклы: while и for

Когда работу надо повторять, на помощь приходят **циклы**. Посчитаем
сумму чисел от 1 до 5 двумя способами. Файл `02-loops.c`.

Сначала `while` — «пока условие истинно, повторяй»:

```c
#include <stdio.h>

int main(void) {
    int n = 5;

    int sum = 0;
    int i = 1;
    while (i <= n) {
        sum = sum + i;
        i = i + 1;
    }
    printf("Сумма от 1 до %d = %d\n", n, sum);
```

Заводим счётчик `i = 1` и копилку `sum = 0`. Пока `i <= n`, прибавляем
`i` к сумме и увеличиваем `i` на единицу. Как только `i` станет `6`,
условие `6 <= 5` ложно — цикл прекращается. Важнейшая деталь: **внутри
цикла счётчик обязан меняться** (`i = i + 1`), иначе условие никогда не
станет ложным и программа зациклится навсегда.

Тот же расчёт короче пишется через `for`. Он собирает три части цикла в
одну строку:

```c
    int sum2 = 0;
    for (int k = 1; k <= n; k++) {
        sum2 = sum2 + k;
    }
    printf("То же через for = %d\n", sum2);
```

В скобках `for` три части через `;`:

1. `int k = 1` — что сделать **один раз** в начале (завести счётчик),
2. `k <= n` — условие, проверяется **перед каждым** проходом,
3. `k++` — что сделать **после каждого** прохода.

`k++` — это сокращение для `k = k + 1`, «увеличь на единицу». Очень
частая запись; есть и брат `k--` — «уменьши на единицу». `for` удобен,
когда заранее знаешь число повторений; `while` — когда повторяешь «пока
что-то держится».

### break и continue

Двумя словами можно управлять циклом изнутри:

- `break` — немедленно **выйти** из цикла целиком,
- `continue` — **пропустить остаток** текущего прохода и перейти к
  следующему.

Покажем оба — печатаем нечётные числа, но останавливаемся после 7:

```c
    for (int x = 1; x <= 10; x++) {
        if (x % 2 == 0) {
            continue;   /* чётные пропускаем */
        }
        if (x > 7) {
            break;      /* после 7 выходим совсем */
        }
        printf("нечётное: %d\n", x);
    }

    return 0;
}
```

`x % 2 == 0` — «остаток от деления на 2 равен нулю», то есть число
чётное; для него `continue` перескакивает к следующему `x`, печать не
выполняется. Как только `x` переваливает за 7, `break` обрывает цикл.
Текст в `/* ... */` — это **комментарий**, компилятор его игнорирует, он
для человека. Запускаем весь `02-loops.c`:

```text
Сумма от 1 до 5 = 15
То же через for = 15
нечётное: 1
нечётное: 3
нечётное: 5
нечётное: 7
```

Оба способа дали `15` (1+2+3+4+5). А нечётные напечатались только до 7 —
`break` сделал своё дело.

## Функции: выносим логику

Когда кусок логики хочется назвать и переиспользовать, его выносят в
**функцию**. Функцию ты уже видел — `main` тоже функция. Заведём свои.
Файл `02-functions.c`:

```c
#include <stdio.h>

/* прототип: обещаем компилятору, что функция есть */
int square(int x);
int max2(int a, int b);

int main(void) {
    printf("square(5) = %d\n", square(5));
    printf("max2(3, 9) = %d\n", max2(3, 9));
    return 0;
}

/* определение: тело функции */
int square(int x) {
    return x * x;
}

int max2(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

Разберём по частям, потому что в одной строке функции много смысла.

Строка `int square(int x);` — это **прототип** (объявление). Она
заканчивается точкой с запятой и не содержит тела. Прототип нужен, чтобы
к моменту вызова в `main` компилятор уже знал: есть функция `square`,
принимает один `int`, возвращает `int`. Прочитаем заголовок слева
направо: `int` — тип возвращаемого значения; `square` — имя; в скобках
`(int x)` — **параметр**: переменная `x` типа `int`, которую функция
получит при вызове.

Ниже, после `main`, идёт **определение** — тот же заголовок, но с телом в
фигурных скобках. `return x * x;` вычисляет квадрат и **возвращает** его
наружу: слово `return` отдаёт значение тому, кто функцию вызвал, и тут же
завершает её.

В `max2` два параметра, `a` и `b`. Внутри — знакомый `if`: если `a`
больше, возвращаем `a`; иначе исполнение дойдёт до `return b`. Заметь — у
функции может быть несколько `return`; срабатывает первый достигнутый.

Вызов выглядит как `square(5)`: пишем имя и в скобках передаём
**аргумент** `5`. Он попадёт в параметр `x`, функция отработает и вернёт
`25`, которое `printf` и напечатает. Запускаем:

```text
square(5) = 25
max2(3, 9) = 9
```

> **Отличие от Си.** `square(5)` — это **прямой вызов функции**: какой
> код выполнить, компилятор знает уже на этапе сборки. В Objective-C ты
> будешь писать иначе — `[obj square:5]`, в квадратных скобках. Это не
> вызов, а **отправка сообщения**: объекту `obj` шлётся сообщение
> `square:`, а нужный метод runtime ищет уже *во время выполнения*. Эта
> разница — сердце всего языка, ей посвящена глава 5. Пока запомни
> картинку: круглые скобки `foo(x)` — вызов функции Си; квадратные
> `[obj foo:x]` — сообщение объекту.

## Проверяем

Все файлы главы лежат в `code/`. Каждый собирается одной командой (это
чистый Си, флаг `-framework Foundation` не нужен):

```text
clang -std=c11 -Wall -Wextra -O2 code/02-vars.c -o prog && ./prog
clang -std=c11 -Wall -Wextra -O2 code/02-divide.c -o prog && ./prog
clang -std=c11 -Wall -Wextra -O2 code/02-input.c -o prog && ./prog
clang -std=c11 -Wall -Wextra -O2 code/02-branch.c -o prog && ./prog
clang -std=c11 -Wall -Wextra -O2 code/02-loops.c -o prog && ./prog
clang -std=c11 -Wall -Wextra -O2 code/02-functions.c -o prog && ./prog
```

Флаги: `-std=c11` — версия языка Си, `-Wall -Wextra` — включить все
предупреждения (пусть компилятор подсказывает), `-O2` — оптимизация. Всё
должно собираться **без единого предупреждения**.

## Частые ошибки

- **`=` вместо `==` в условии.** `if (x = 5)` не сравнивает, а
  присваивает `x` пятёрку — и условие всегда истинно. Сравнение — `==`.
- **Целочисленное деление.** `int avg = sum / count;` режет дробь.
  Нужна дробь — сделай операнд дробным: `(double)sum / count`.
- **Забытый `&` в `scanf`.** `scanf("%d", age)` без `&` — почти
  гарантированное падение. В `scanf` перед переменной всегда `&`.
- **Бесконечный цикл.** В `while` забыл менять счётчик (`i = i + 1`) —
  условие никогда не станет ложным, программа висит. Прерывается
  `Ctrl+C`.
- **Перепутал кавычки.** `'A'` (одинарные) — символ `char`. `"A"`
  (двойные) — строка. Для `char` нужны одинарные.
- **Потерял `;`.** Компилятор укажет на строку *после* пропущенной точки
  с запятой — смотри на предыдущую.

## Упражнения

1. Заведи две переменные `double` (рост и вес) и напечатай их через
   `%.2f`. Посчитай ИМТ (вес / рост²) и выведи результат.
2. Перепиши `02-divide.c` так, чтобы числа `apples` и `people` читались с
   клавиатуры через `scanf`. Не забудь `&` и проверку возврата.
3. Напиши цикл `for`, печатающий таблицу умножения на 7 (от `7×1` до
   `7×10`).
4. Сделай функцию `int isEven(int n)`, которая возвращает `1` для чётных
   и `0` для нечётных (подсказка: `n % 2`). Проверь её в цикле для чисел
   от 1 до 10.
5. Через `while` найди наименьшее число, квадрат которого больше 1000.

## Что мы получили

Теперь у тебя есть вся процедурная база Си: переменные и типы, арифметика
с её ловушкой целочисленного деления, печать через `printf` и ввод через
`scanf` со знаком `&`, ветвления `if`/`else` с операторами сравнения и
логики, циклы `while`/`for` с `break`/`continue` и собственные функции с
прототипами и `return`. Этого хватит, чтобы писать осмысленные программы
— и этого же хватит, чтобы понять объектную часть, когда мы до неё
дойдём.

Попутно мы трижды заглянули вперёд: `printf` против `NSLog %@`, `==`
против `isEqualToString:`, вызов `foo(x)` против сообщения `[obj foo:x]`.
Держи эти контрасты в голове — они вернутся.

В главе 3 разберём то, на чём в Си держится буквально всё, включая
объекты Objective-C, — **указатели и память**. Тот самый знак `&` из
`scanf` и звёздочка `*` из `NSString *` оттуда родом.
